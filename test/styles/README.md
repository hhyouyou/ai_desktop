# UI 风格探索样张

同一套内容（首页：主视觉 / 工具区 / AI 区 / 热点区），6 种不同的视觉语言。**纯静态，没有功能，不影响线上版本。**

## 怎么看

- 打开 [`index.html`](index.html)：6 套风格的缩略对比 + 每套的「打开完整页面」链接
- 或直接打开单页：
  - [`01-editorial.html`](01-editorial.html) — 编辑杂志
  - [`02-swiss.html`](02-swiss.html) — 瑞士网格
  - [`03-soft.html`](03-soft.html) — 柔和卡片
  - [`04-dark.html`](04-dark.html) — 暗色终端
  - [`05-warm.html`](05-warm.html) — 日式暖纸
  - [`06-bento.html`](06-bento.html) — Bento 现代

截图在 `preview/`。

## 六套风格速览

| # | 风格 | 主色 | 字体气质 | 最适合 |
|---|---|---|---|---|
| 01 | 编辑杂志 | 米白纸 + 墨黑 + 陶红 | 宋体标题 / 正文无衬线 | 内容型个人站，克制、耐看 |
| 02 | 瑞士网格 | 纯白 + 黑 + 单点红 | Helvetica 粗标题 | 设计师向、强调秩序与信息密度 |
| 03 | 柔和卡片 | 浅灰蓝 + 低饱和蓝 | 无衬线，圆角软阴影 | 面向大众的工具产品，亲和 |
| 04 | 暗色终端 | 近黑 + 荧光绿 | 等宽字 | 开发者工具、长时间浏览 |
| 05 | 日式暖纸 | 米白 + 陶土 + 橄榄 | 宋体 + 纸纹 | 生活化、手作感、慢节奏 |
| 06 | Bento 现代 | 浅灰白 + 白卡 + 靛蓝 | 无衬线，大圆角细边 | 2025 产品官网，现代但克制 |

## 改一套看效果

所有页面由 [`generate.mjs`](generate.mjs) 生成（共享同一段 HTML 结构 + 每套独立的 CSS）：

```bash
node test/styles/generate.mjs
```

改动 `styles` 数组里某个风格的 `css` 字符串，重新跑一次即可；调好之后我再把它落到正式页面。
