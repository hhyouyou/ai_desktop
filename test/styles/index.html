块集 · UI 风格探索

同一套内容（首页：主视觉 / 工具 / AI / 热点），6 种不同的视觉语言。纯静态样张，没有功能，也不影响线上版本。

点标题右侧「打开完整页面」可看 1440 宽的真实排版；下面的缩略框是真实 iframe 渲染。

01 · 编辑杂志

打开完整页面 ↗

纸感米白 + 宋体标题 + 双色克制，靠字号、留白和细分隔线组织信息。最安静、最“读物感”。

02 · 瑞士网格

打开完整页面 ↗

纯白 + 严格 12 栏 + 单点红，Helvetica 风格粗标题，信息密度高但秩序感强。最“产品/设计公司”。

03 · 柔和卡片

打开完整页面 ↗

浅灰蓝底 + 大圆角 + 软阴影 + 低饱和蓝，卡片轻浮动。最“亲切、现代 SaaS”，但整体最低调。

04 · 暗色终端

打开完整页面 ↗

近黑底 + 等宽字 + 单点荧光绿 + 网格底纹。最“开发者/极客”，长时间看最不刺眼。

05 · 日式暖纸

打开完整页面 ↗

米白纸纹 + 宋体 + 陶土/橄榄色点缀 + 大留白。最“手作、生活感”，适合内容型个人站。

06 · Bento 现代

打开完整页面 ↗

浅灰白 + 白卡片 + 细边 + 靛蓝单强调 + 大圆角。最“2025 产品官网”，克制但有现代感。
