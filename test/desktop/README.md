# 「在线桌面」方向样张

产品思路：**一个浏览器里的桌面**——日常工具、可切换模型且保留历史的 AI 对话、待办规划、聚合热点，都在同一屏完成。所以 UI 直接借用「壁纸 / 应用图标 / 窗口 / Dock / 小组件」这套大家已经会用的桌面心智。

**纯静态样张，没有功能，不影响 `app/` 线上版本。**

## 怎么看

- 打开 [`index.html`](index.html)：6 套桌面方案的缩略对比
- 或直接打开单页：

|---|---|---|
| [`01-clear-desktop.html`](01-clear-desktop.html) | 清爽桌面 | 浅色壁纸 + 白色窗口 + 底部 Dock，最好懂、最平衡 |

## 改一套看效果

```bash
node test/desktop/generate.mjs
```

`01/02/03` 共用同一个桌面外壳（只换 CSS 主题），`04/05/06` 是独立布局。改颜色、圆角、模糊、间距都只需动对应的 CSS 字符串，重新跑一次即可。

## 落地时会怎么拆

桌面隐喻只放在**首页**，内页（工具详情、AI 会话、待办、热点）仍用轻量列表/卡片布局，避免每页都"开窗口"。

| 桌面元素 | 正式版实现 |
|---|---|
| 壁纸 | 一张 CSS 渐变 / 可选自定义 |
| 应用图标 | 左侧 rail（桌面）→ 移动端变成底部 Tab |
| 窗口 | 卡片容器，支持最小化 / 展开（可选，不做拖拽） |
| Dock | 移动端底部导航 / 桌面端快捷入口 |
| 小组件 | 时钟、热点、AI 快捷、待办进度，可开关 |
