块集 · 「在线桌面」方向探索

产品思路：一个浏览器里的桌面 —— 日常工具、可切换模型且保留历史的 AI 对话、待办规划、聚合热点，都在同一屏完成。

6 个方案都在用「壁纸 / 应用图标 / 窗口 / Dock 或小组件」表达桌面；每套附带一个 slogan 试试语感。点右侧「打开完整页面」看 1440 宽真实排版。

01 · 清爽桌面

打开完整页面 ↗

浅色渐变壁纸 + 白色窗口 + 底部 Dock + 右侧小组件。最像“浏览器里的桌面”，干净、亲和、信息不挤。

Slogan：你的在线桌面 · 工具、AI、待办、热点一屏收好

02 · 毛玻璃桌面

打开完整页面 ↗

深色渐变壁纸 + 半透明毛玻璃窗口 + 顶部菜单栏。最有“系统感”和高级感，适合做主视觉，但深色阅读内容稍重。

Slogan：打开浏览器，就是你的桌面

03 · 极简工作台

打开完整页面 ↗

近白底 + 细边框分栏 + 单一墨绿强调色。像一张排好版的工作台，最克制，最不容易看腻。

Slogan：少一点，但够用

04 · 平铺工作台

打开完整页面 ↗

深色 + 无圆角四宫格平铺：工具 / AI / 待办 / 热点各占一格，像 tiling window manager。密度最高，开发者味最重。

Slogan：四块屏，装下一天的工作流

05 · 纸面工作台

打开完整页面 ↗

米白纸面 + 图钉便签 + 宋体标题。把“桌面”理解成一张真的书桌，温和、有手作感，适合偏内容的个人站。

Slogan：一张桌子，放下今天要做的事

06 · 小组件主屏

打开完整页面 ↗

把桌面做成“主屏小组件”：时钟、工具、AI、待办、热点各占一块 widget。最容易被理解，移动端也天然好落地。

Slogan：所有常用，都在首屏
