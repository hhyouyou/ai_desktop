# 块集小镇（/town）

一个可以走进去的等距 3D 小镇。十三栋建筑，每栋对应站点的一个功能入口：
点击建筑 → 人物走到门口 → 按 `↵` 进入对应页面。

定位是「增强入口」，不是唯一入口：`/town` 同时输出一份语义化的建筑导航（`sr-only`），
搜索引擎和读屏软件读到的是真实链接；3D 只是表现层。

## 每栋的专属造型

十三栋共用一套纸模语言（米白墙、陶土描边、门与招牌的位置一致），
但屋顶和特征构件按功能重做，并带缓慢动画。全部由代码生成，没有模型文件。

| 建筑 | 造型梗 | 动画 |
|---|---|---|
| 工坊 | 单坡厂房 + 正面巨型齿轮 + 屋顶插着一把扳手 | 齿轮缓慢转动 |
| 电报局 | 天线塔 + 顶端放电球 + 墙面摩斯码灯带 | 三个消息方块上下浮动 |
| 广播站 | 屋顶大喇叭 + 三圈声波环 | 声波向外扩散并淡出 |
| 书店 | 翻开的书页屋顶 + 三本斜插的巨书 | — |
| 天文台 | 圆顶 + 掀开的天窗 + 大望远镜 | 三颗星球环绕公转 |
| 地图亭 | 悬挑顶棚 + 屋顶大罗盘 | 指针缓慢旋转 |
| 报社 | 两个印刷滚筒 + 一张吐出的号外 + 烟囱 | 两个滚筒反向转动 |
| 市政厅 | 柱廊 + 三角山花 + 徽章 + 中央圆顶 + 台阶 | — |
| 画室 | 斜天窗 + 屋顶巨型画架（画布上有涂鸦） | 四颗颜料球浮动 |
| 任务板 | 斜木板棚 + 屋檐木梁 | 三张便签飘起再落下 |
| 打字机铺 | 屋顶纸卷 + 延伸的纸带 + 键盘按键 | — |
| 咖啡馆 | 屋顶倒扣的大咖啡杯（带杯柄） | 三缕热气浮动 |
| 钟楼 | 挑檐 + 四棱尖顶 + 风向标 | 钟摆左右摆动、风向标旋转 |

动画不走 React，而是在创建时给对象打标记（`spinY` / `floatY` / `orbit` / `swing` / `pulse`），
场景初始化时 `traverse` 收集一次，每帧统一推进。这样新增动画只需要在造型里加一行标记。

## 地点 = 主楼 + 附属

一个地点不只是一栋房子，而是一组东西。数据模型里用 `SiteDef.annexes` 描述：

```ts
{ id: "cafe", annexes: [
  { kind: "fence", x: -8.4, z: 21.2, rot: 0, length: 3.4 },
  { kind: "table", x: -7.8, z: 21 },
  { kind: "parasol", x: -7.8, z: 21, accent: "coral" },
  { kind: "chalkboard", x: -10.4, z: 22.4, rot: -0.4 },
  ...
]}
```

附属构件（`lib/town/site.ts`）：

| kind | 用途 |
|---|---|
| `shed` | 附属小屋 / 印刷车间，带卷帘门 |
| `stall` | 露天书摊，带书架和遮阳棚 |
| `table` / `parasol` | 户外咖啡桌与阳伞 |
| `fence` | 围出院落的矮栅栏 |
| `rack` | 晾报架，挂着当天的号外 |
| `chalkboard` | A 字小黑板，写今日特调 |
| `well` | 院里的水井 |
| `barrels` / `planter` / `bench` / `lamp` | 桶、花坛、长椅、路灯 |
| `pad` | 夯土场院，把门前这块地压出来（`w` / `d` 指定尺寸） |
| `workbench` | 露天工作台：深色台面、台钳、锯、锤、红色工具箱、木凳 |
| `lumber` | 木料堆：三层原木 + 斜靠的板子 + 锯末堆 |
| `anvil` | 铁砧：木墩、砧身、尖角、砧面上的红铁、淬火桶 |
| `cart` | 手推车：两轮板车，暗红车厢，装着木箱与刨花 |
| `shelf` | 料架：三层木架，摆着木箱、铁桶、立板、没上漆的凳子 |
| `grindstone` | 砂轮：木架 + 石轮 + 水槽 + 摇柄，石轮会自己转 |
| `paving` | 石板铺装：分缝、路缘石、中轴石带、中央圆形石饰（`w` / `d` 指定尺寸） |
| `plinth` | 入口三级石阶 |
| `topiary` | 修剪成球的树：木花箱 + 杆 + 球冠 |
| `flagpole` | 旗杆：石座、杆、顶球、会飘的旗 |
| `notice` | 公告栏：立柱、板面、标题条、三张钉着的告示、小雨檐 |
| `monument` | 纪念柱：三级基座 + 四棱碑身 + 铭牌 + 金顶 |

目前做了五个院落：

- **咖啡馆**：围栏露台 + 三张圆桌 + 两把阳伞 + 小黑板 + 花坛
- **报社**：印刷车间小屋 + 三面院墙 + 晾报架 + 水井 + 木桶堆
- **书店**：露天书摊 + 两张长椅 + 花坛
- **工坊**：夯土场院 + 工作台（带木凳）+ 木料堆 + 料架 + 手推车 + 铁砧 + 转动的砂轮
- **市政厅**：石板前广场（10 × 9.2）+ 三级石阶 + 六棵球树 + 两根旗杆 + 公告栏 + 纪念柱 + 两张长椅

其余八处先保留单栋建筑，但地块已经按「院落」的尺度留好了空间，后续可以一个个补。

### 工坊院子的两处设计决定

**主楼从 (-12,-25) 西移到 (-15,-25)，仍然朝东。** 一开始试着让它朝南、把院子放在门前，结果院子正好被南边的打字机铺挡住——等距视角里「门前」就是「被南侧建筑遮挡的方向」。改成朝东、院子摆在主楼东侧的临街空地，视线才通。

**木色分了三档。** 一开始所有物件都是同一个木色，缩到全景就糊成一片棕色。现在工作台是深胡桃色台面 + 红色铁皮工具箱，手推车刷成暗红，料架与木料保持浅木色——一眼能分出「哪个是台子、哪个是车、哪个是料」。

### 市政厅广场的三次调色

**一、主楼北移 3.5。** 原来它贴着南横街，门前根本没有进深，人走到门口其实是站在马路上。移到 z = 4.5 之后，楼与街之间让出 3.5 米的广场。

**二、铺装试了三轮才读得出来。** 先是 `#E8E0CD`（比地面亮一点）→ 看不出来；换成更亮的 `#EFE8D7` → 还是看不出来；最后反过来压暗到 `#CFC6AE`（中灰石材）并且**加了一圈深色路缘石**，广场才真正从土地里"切"出来。结论：在等距视角下，靠明度差不够，得靠**边界**。

**三、广场加深之后需要一个中心。** 报社搬走、广场加到 10 × 9.2 之后，中间空出一大片。补了一根
纪念柱（三级基座 + 四棱碑身 + 铭牌 + 金顶），正好压在铺装的圆形石饰上，广场才有一个视线的落点。

**四、动线用一条石带画出来。** 广场正中铺了一条 1.3 米宽、颜色略深的石带，从街口直通石阶，中间嵌一个圆形石饰。没有这条带子，广场只是一块空地；有了它，视线会自己顺着走到门口。

## 平面结构

80 × 80 的地块（`TOWN_SIZE = 40`），街道切出大小不等的街区：

```
        ┌──────┬──────────┬──────────┬──────┐
        │ 住宅 │  工坊    │  电报局  │ 广播站│
        │      │          │          │ 仓库  │
   北横街├──────┼──────────┼──────────┼──────┤
        │ 天文台│  任务板  │  报社    │ 画室  │
        │ 地图亭│  [广场]  │  市政厅  │      │
   南横街├──────┼──────────┼──────────┼──────┤
        │ 公园 │  打字机铺│  钟楼    │ 住宅  │
        │      │  咖啡馆  │          │ 水塔  │
        └──────┴──────────┴──────────┴──────┘
```

- **主街**纵贯南北（宽 7.25），但两端各偏 2.5 米，不是一条笔直的轴
- **两条横街**（宽 5.1–5.4）走向各偏 1.2–1.7°，与主街形成两个歪着的路口
- **西纵街**走到 z ≈ 14 就断了，南段靠一条**斜巷**（从公园斜插向东南）接上
- **市集广场**在主街中段，圆形石板地（半径 6.6）+ 喷泉 + 长椅 + 花坛 + 三个摊位
- **公园**在西南角（11.4 × 20.8），是镇里最大的一片绿地，**住宅**在西北与东南，**仓库**在东北，**水塔**在东南边缘

所有街道都是**直线段**。不规整来自「走向差异 + 长度不一 + 断头 + 斜巷」，而不是弯曲——
等距视角下弯道会产生高低起伏的错觉，反而更难受。

建筑之间留 2–6 米空隙。建筑占地按 1.55 倍放大、位置按 1.25 倍外扩、高度按 1.55 倍抬升——
**楼比地长得快**，镇子才从「一排小房子」变成「一座镇子」。

### 报社为什么搬走了

原来报社和市政厅在同一块地上，前后只隔 1.3 米——从等距视角看，两栋楼几乎叠在一起，
中间还夹着市政厅的广场。

调整的办法不是硬挪，而是**和画室对调**：

| 地点 | 原位置 | 现位置 |
|---|---|---|
| 报社 | 主街中段西侧（紧贴市政厅） | 东侧独立街区 `(30, 2.5)` |
| 画室 | 东侧独立街区 `(30, 2.5)` | 东南角 `(26, 21)` |

这样两个都说得通：报社临街、有独立的印报院子；画室搬到安静的居住区，反而更像画室。
市政厅则独占了整个街区，广场从 7.2 米深加到 9.2 米。

### 一次整体放大

地块从 64 × 64 扩到 80 × 80，同一批坐标按三个不同比例变换：

| 量 | 倍数 | 结果 |
|---|---|---|
| 位置（x / z、街道、配景） | ×1.25 | 地块与间距一起张开 |
| 建筑占地（w / d） | ×1.55 | 楼比地长得快，占满自己的地块 |
| 建筑高度（h） | ×1.55 | 保持比例，不然楼会变成扁盒子 |

**高度必须跟占地同比例。** 第一次只放大了占地（高度 ×1.25），结果所有楼都成了又宽又矮的扁盒，
看着不像「大」而像「压扁」。补齐高度之后才立住。

顺带改了两处因为变大而失效的东西：

- **立面开窗**原来是固定两扇 0.66 × 0.74 的窗，楼一大就成了一张白墙。现在按墙面宽度算列数
  （每 2.4 米一列）、按高度算行数（超过 4.6 米开两排），并且给等距视角能看到的那一侧也开窗。
- **门口落点**原来写死 `d/2 + 2.3`，建筑变大后这个点会落进碰撞圈里，人被挤到旁边。
  改成 `max(d/2 + 2.4, max(w,d) * 0.62 + 1)`，永远在障碍圈外。

## 视觉方向：纸模小镇

选这个方向是因为它让小镇成为「在线桌面」的延伸，而不是第二个产品：
米白纸面、陶土描边、剪纸投影、纸片小人，和默认主题「纸面工作台」同源。

三层地面色用来区分道路层级，这是小镇能不能「读出来」的关键：

| 层级 | 色值 | 作用 |
|---|---|---|
| 地面 | `#E6DAC0` | 街区底色 |
| 路面 | `#C7BCA3` | 深一档，街道因此可辨 |
| 人行道 | `#F5EFE1` | 浅一档，贴在路两侧，形成路缘 |
| 路缘石 | `#B3A68C` | 0.16 宽细条，把路和人行道分开 |

建筑主体墙 `#FBF6EA`，侧面 `#E9DCC4`，描边 `#A2573A`；屋顶用各建筑的强调色浅调，
尖顶用饱和色。招牌、门、遮阳篷、旗帜是小面积撞色，避免整体发闷。

## 让小镇不像规划图

早期版本是笔直的正交路网，看着像一张总平面图。现在做了四件事把它「揉开」：

### 1. 街道是直的，但走向不一

每条街都是直线段（`BoxGeometry` + 旋转），靠三件事打破规整：
**走向各偏 1–2°**、**长度不同**、**西纵街中途断头**。
另有一条斜巷（-22.4, 13.6 → -14.6, 25.4）从公园斜插出去，是路网里唯一的斜线。

> 试过用 `CatmullRomCurve3` 做弯曲街道，但在等距视角下弯道会产生高低起伏的错觉，
> 反而比直线更难受。所以**不规整的来源是「拓扑」，不是「曲率」**。

### 2. 街区里铺后院草地

八块圆角矩形草坪（`createYard`）填进建筑背后的空地。颜色 `#C2D49C`，比地面 `#E6DAC0`
绿一档，既压住空旷感，又不抢街道。

### 3. 绿植分三层

| 层级 | 做法 | 数量 |
|---|---|---|
| 乔木 | 圆锥树冠 + 树干，公园与沿街 | 26 棵 |
| 灌木 | `IcosahedronGeometry` + `InstancedMesh`，贴墙与街角 | 39 丛 |
| 地被 | 草丛锥体 + 花丛小球，围绕灌木生成 | 130 簇 |

灌木和花丛都做了确定性伪随机（`hash()`），每次刷新长得一样，不会跳。

### 4. 生活痕迹

- **篱笆**围出住宅前院，中间留一米的门洞
- **晾衣绳**挂四块不同颜色的布，风一吹（静止，但有朝向差异）
- **自行车**靠墙停在工坊、书店、咖啡馆、市政厅旁
- **木箱**堆在仓库与工坊后门，**水桶**放在咖啡馆墙根
- **垃圾桶**在广场、公园与街角，**花盆**在每个门口
- **路标**立在两个主要路口，**门垫**每栋建筑门口都有一块

数量多的物件（灌木、花、草）用 `InstancedMesh` 合并，避免 draw call 爆炸。

## 实现要点

- **相机**：`OrthographicCamera` 沿 `(1,1,1)` 方向，等距俯角 35.26°；只允许缩放，不做自由环绕
- **光照**：半球光 + 主平行光（2048 阴影贴图，覆盖 ±38）+ 冷色补光
- **材质**：`MeshToonMaterial` + 4 阶 `gradientMap`，描边用 `EdgesGeometry + LineSegments`
- **朝向**：主街西侧建筑门朝 `+X`（正对主街），其余朝 `+Z`（正对镜头）；两种朝向在等距下都可见
- **门口落点**：`max(d/2 + 2.4, max(w,d) * 0.62 + 1)`，必须大于建筑碰撞半径，否则人物会被挤到侧面
- **寻路**：49×49 网格，建筑 / 装饰建筑 / 喷泉 / 水池 / 摊位标为障碍
- **键盘**：WASD / 方向键按「屏幕方向」映射到等距世界方向，不是按世界轴
- **到达**：走完路径后回调 React，弹出进入卡片，`↵` 触发路由跳转

## 降级与可访问性

- WebGL 初始化失败 → 自动切列表视图（真实 `<a>` 链接）
- 右上角随时可手动切「列表视图 / 回到小镇」
- `prefers-reduced-motion` 下关闭所有过渡与加载动画
- 页面底部有 `sr-only` 的完整建筑导航，供搜索引擎与读屏

```bash
npm run dev

```

## 已知限制

- 阴影和几何都是即时生成的，首次进入需要下载 3D 引擎（约 160 KB gzip）
