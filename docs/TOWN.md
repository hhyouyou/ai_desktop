# 块集小镇（/town）

一个可以走进去的等距 3D 小镇。十三栋建筑，每栋对应站点的一个功能入口：
点击建筑 → 人物走到门口 → 按 `↵` 进入对应页面。

定位是「增强入口」，不是唯一入口：`/town` 同时输出一份语义化的建筑导航（`sr-only`），
搜索引擎和读屏软件读到的是真实链接；3D 只是表现层。

## 平面结构

56 × 56 的地块，街道切出大小不等的街区：

```
        ┌──────┬──────────┬──────────┬──────┐
        │ 住宅 │  工坊    │  电报局  │ 广播站│
        │      │          │          │ 仓库  │
   北横街├──────┼──────────┼──────────┼──────┤
        │ 天文台│  任务板  │  报社    │ 画室  │
        │ 地图亭│  [广场]  │  市政厅  │      │
   南横街├──────┼──────────┼──────────┼──────┤
        │ 公园 │  打字机铺│  钟楼    │ 住宅  │
        │      │  咖啡馆  │          │ 水塔  │
        └──────┴──────────┴──────────┴──────┘
```

- **主街**纵贯南北（宽 5.6），但两端各偏 2 米，不是一条笔直的轴
- **两条横街**（宽 4.1–4.3）走向各偏 1–1.7°，与主街形成两个歪着的路口
- **西纵街只到 z = 9 就断了**，南段靠一条**斜巷**（从公园斜插向东南）接上
- **市集广场**在主街中段，圆形石板地 + 喷泉 + 长椅 + 花坛 + 三个摊位
- **公园**在西南角（9.4 × 14.6），是镇里最大的一片绿地，**住宅**在西北与东南，**仓库**在东北，**水塔**在东南边缘

所有街道都是**直线段**。不规整来自「走向差异 + 长度不一 + 断头 + 斜巷」，而不是弯曲——
等距视角下弯道会产生高低起伏的错觉，反而更难受。

建筑之间留 3–8 米空隙，最窄处（工坊与北横街）也有 2.5 米。

## 视觉方向：纸模小镇

选这个方向是因为它让小镇成为「在线桌面」的延伸，而不是第二个产品：
米白纸面、陶土描边、剪纸投影、纸片小人，和默认主题「纸面工作台」同源。

三层地面色用来区分道路层级，这是小镇能不能「读出来」的关键：

| 层级 | 色值 | 作用 |
|---|---|---|
| 地面 | `#E6DAC0` | 街区底色 |
| 路面 | `#C7BCA3` | 深一档，街道因此可辨 |
| 人行道 | `#F5EFE1` | 浅一档，贴在路两侧，形成路缘 |
| 路缘石 | `#B3A68C` | 0.16 宽细条，把路和人行道分开 |

建筑主体墙 `#FBF6EA`，侧面 `#E9DCC4`，描边 `#A2573A`；屋顶用各建筑的强调色浅调，
尖顶用饱和色。招牌、门、遮阳篷、旗帜是小面积撞色，避免整体发闷。

## 让小镇不像规划图

早期版本是笔直的正交路网，看着像一张总平面图。现在做了四件事把它「揉开」：

### 1. 街道是直的，但走向不一

每条街都是直线段（`BoxGeometry` + 旋转），靠三件事打破规整：
**走向各偏 1–2°**、**长度不同**、**西纵街中途断头**。
另有一条斜巷（-22.4, 13.6 → -14.6, 25.4）从公园斜插出去，是路网里唯一的斜线。

> 试过用 `CatmullRomCurve3` 做弯曲街道，但在等距视角下弯道会产生高低起伏的错觉，
> 反而比直线更难受。所以**不规整的来源是「拓扑」，不是「曲率」**。

### 2. 街区里铺后院草地

八块圆角矩形草坪（`createYard`）填进建筑背后的空地。颜色 `#C2D49C`，比地面 `#E6DAC0`
绿一档，既压住空旷感，又不抢街道。

### 3. 绿植分三层

| 层级 | 做法 | 数量 |
|---|---|---|
| 乔木 | 圆锥树冠 + 树干，公园与沿街 | 26 棵 |
| 灌木 | `IcosahedronGeometry` + `InstancedMesh`，贴墙与街角 | 39 丛 |
| 地被 | 草丛锥体 + 花丛小球，围绕灌木生成 | 130 簇 |

灌木和花丛都做了确定性伪随机（`hash()`），每次刷新长得一样，不会跳。

### 4. 生活痕迹

- **篱笆**围出住宅前院，中间留一米的门洞
- **晾衣绳**挂四块不同颜色的布，风一吹（静止，但有朝向差异）
- **自行车**靠墙停在工坊、书店、咖啡馆、市政厅旁
- **木箱**堆在仓库与工坊后门，**水桶**放在咖啡馆墙根
- **垃圾桶**在广场、公园与街角，**花盆**在每个门口
- **路标**立在两个主要路口，**门垫**每栋建筑门口都有一块

数量多的物件（灌木、花、草）用 `InstancedMesh` 合并，避免 draw call 爆炸。

## 实现要点

- **相机**：`OrthographicCamera` 沿 `(1,1,1)` 方向，等距俯角 35.26°；只允许缩放，不做自由环绕
- **光照**：半球光 + 主平行光（2048 阴影贴图，覆盖 ±38）+ 冷色补光
- **材质**：`MeshToonMaterial` + 4 阶 `gradientMap`，描边用 `EdgesGeometry + LineSegments`
- **朝向**：主街西侧建筑门朝 `+X`（正对主街），其余朝 `+Z`（正对镜头）；两种朝向在等距下都可见
- **门口落点**：`d/2 + 2.3`，必须大于建筑碰撞半径，否则人物会被挤到侧面
- **寻路**：49×49 网格，建筑 / 装饰建筑 / 喷泉 / 水池 / 摊位标为障碍
- **键盘**：WASD / 方向键按「屏幕方向」映射到等距世界方向，不是按世界轴
- **到达**：走完路径后回调 React，弹出进入卡片，`↵` 触发路由跳转

## 降级与可访问性

- WebGL 初始化失败 → 自动切列表视图（真实 `<a>` 链接）
- 右上角随时可手动切「列表视图 / 回到小镇」
- `prefers-reduced-motion` 下关闭所有过渡与加载动画
- 页面底部有 `sr-only` 的完整建筑导航，供搜索引擎与读屏

## 验证

```bash
npm run dev
node scripts/town-check.mjs
```

脚本会检查 canvas、WebGL 上下文、是否降级、控制台错误，并模拟
`goToBuilding('workshop')` 验证「走到门口 → 出现卡片」，最后输出两张截图到 `.tmp/`。

## 已知限制

- 阴影和几何都是即时生成的，首次进入需要下载 3D 引擎（约 160 KB gzip）
- 昼夜两套氛围还没做：目前固定日间纸模，`glass` / `tiling` 主题下也不会变暗
- 建筑内部没有二级菜单，点击直接跳转页面
- 人物只有行走动画，没有待机小动作
- 街区内部还是空地，没有后院、篱笆、晾衣绳这类生活痕迹
- 街道两端直接断在地块边缘，没有向外的延伸暗示
